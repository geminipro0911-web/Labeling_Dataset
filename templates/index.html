🎯 Bounding Box Rules:

  • Tight Boundaries: Draw the rectangular box snugly around the defect without leaving excessive background margins.
  • Separate Instances: If there are multiple defect spots, draw a separate box around each defect.
  • Do Not Clip: Ensure all defect edges are completely enclosed inside the box.
  • Single Defect Class: All boxes inherit the target defect class assigned to this image.
  • Accidental Clicks: Boxes smaller than 5×5 pixels are automatically ignored.
  • Keyboard Shortcuts: Ctrl+Z Undo | Delete Delete selected | A Back | D / Enter Next.
✔ CORRECT LABELING

Tight bounding box fits precisely around defect edges with minimal background.

✖ INCORRECT LABELING

Too loose (wastes training capacity) or partially truncates the defect.
